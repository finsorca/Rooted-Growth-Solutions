  <!-- THE PROBLEM -->

  <section id="problem">

    <div class="container">

      <div class="section-tag">The Challenge</div>

      <h2>A Critical Gap in <em>Smallholder Support</em></h2>

      <div class="problem-grid">

        <div class="problem-text">

          <p>

            South Africa's 250 000 smallholder farmers are the backbone of rural livelihoods, yet they remain underserved by a system that supports them in isolation — technical advice here, financial training there — but never both together.

          </p>

          <p>

            NGOs, government institutions, and private organisations provide support in fragments. The missing link is an integrated approach that connects <em>where</em> a farmer works and <em>how</em> that translates into profit or loss.

          </p>

          <p>

            Without that connection, planning decisions suffer, resources are wasted, and farmers struggle to grow sustainable enterprises — despite access to land, labour, and markets.

          </p>

        </div>

        <div class="problem-cards">

          <div class="prob-card">

            <h4>No Structured Financial Systems</h4>

            <p>Most smallholder farmers lack access to farm-level financial tools — enterprise budgets, cash flow plans, or cost structures that help them understand profitability.</p>

          </div>

          <div class="prob-card">

            <h4>Limited Farm-Level Data</h4>

            <p>Decisions are made without reliable spatial or production data — leaving farmers unable to identify underperforming zones or optimise land use.</p>

          </div>

          <div class="prob-card">

            <h4>Disconnected Planning & Finance</h4>

            <p>Even when support exists, spatial analysis and financial management are delivered in isolation — creating plans that look good on paper but don't survive contact with the season.</p>

          </div>

          <div class="prob-card">

            <h4>Poor Resource Allocation</h4>

            <p>Without knowing which land units are productive and at what cost, farmers spread inputs too thin or invest where returns are low — eroding margins over time.</p>

          </div>

        </div>

      </div>

    </div>

  </section>

    function toggleMenu() {

      const nav = document.getElementById('navLinks');

      nav.classList.toggle('open');

    }


    // Close menu on link click

    document.querySelectorAll('.nav-links a').forEach(a => {

      a.addEventListener('click', () => {

        document.getElementById('navLinks').classList.remove('open');

      });

    });


    // Scroll-reveal

    const observer = new IntersectionObserver((entries) => {

      entries.forEach(e => {

        if (e.isIntersecting) {

          e.target.style.opacity = '1';

          e.target.style.transform = 'translateY(0)';

        }

      });

    }, { threshold: 0.12 });


    document.querySelectorAll('.service-card, .prob-card, .client-card, .team-card, .step, .metric-box').forEach(el => {

      el.style.opacity = '0';

      el.style.transform = 'translateY(20px)';

      el.style.transition = 'opacity 0.55s ease, transform 0.55s ease';

      observer.observe(el);

    });


    // Contact form

    function handleSubmit(e) {

      e.preventDefault();

      document.getElementById('form-success').style.display = 'block';

      e.target.reset();

    }


    // Shrink nav on scroll

    window.addEventListener('scroll', () => {

      const nav = document.querySelector('nav');

      if (window.scrollY > 60) {

        nav.style.padding = '0.75rem 4rem';

      } else {

        nav.style.padding = '1.2rem 4rem';

      }

    });
